A beginner-friendly ATM Simulation System developed using Java SE

## Features

- Check account balance
- Deposit money
- Withdraw money
- View transaction history
- Simple menu-driven interface

## Technologies Used

- Java
- Java SE
- Object-Oriented Programming
- ArrayList
- Scanner
- Enum

## How to Run

1. Clone or download this repository.
2. Open AtmSystem.java in a Java-supported IDE.
3. Compile and run the program.
4. Follow the options displayed in the console.

## Project Purpose

This project was created to practice Java programming concepts and understand how basic ATM and banking operations can be implemented using Java.
